# 交互流程说明书（人工核对用）

> 用途：和用户核对当前交互流程，排查"卡住 / 乱码 / 不知道下一步"一类问题。

## 一、启动

1. Windows 双击 `start.bat`；macOS/Linux 运行 `node server.mjs`
2. 打开 **http://127.0.0.1:8792**（端口见 `.env` 的 `PORT`，默认 8792；若 8791 被其他工具占用请用当前端口）
3. 侧栏状态卡显示「LLM 已配置」= 全功能可用；「LLM 未配置」= 只能离线评估

> ⚠️ 端口核对：本工具返回 `{"ok":true,"llm":true}`。若访问后看到**别的界面**（如"剧情工具"），说明连到了其他程序，换端口即可。

## 二、三步使用动线（快捷功能）

| 步骤 | 侧栏按钮 | 填入的提示词模板 | 说明 |
|---|---|---|---|
| **① 立项评估** | 📊 评估我的项目 | `评估立项：《XXX》2D 肉鸽卡牌，2人团队，计划12个月上线——值不值得做？` | 第一步：自动调研 + 评分报告 |
| **② 看结论** | 📌 输出项目评估结论 | `输出项目「XXXXXX」的评估结论` | 读本地档案复述结论（**不重跑评估**） |
| **② 深挖** | 🔍 深挖品类与竞品 | `分析「XXXXXX」品类当前的市场趋势、竞争格局与进入机会` | 继续调研，补充竞品与差异化机会 |
| **③ 导出** | ⤓ 导出报告 PDF | `导出项目「XXXXXX」的最近一次评估报告` | 前端本地导出，零 token 成本 |

> 所有按钮点击后填入输入框并自动选中 `XXX` 占位符，改完直接回车发送。

## 三、三种对话模式

| 模式 | 触发方式 | 流程 | 耗时 |
|---|---|---|---|
| **立项评估** | 消息含「立项 / 评估 / 值不值得做 / 能不能做 / 做多久 / 多久上线 / 还能进场吗 / 红海 / 饱和」 | 4 步流水线：①理解项目 → ②采集 Steam 与网络数据 → ③六维评分+工期+窗口 → ④报告先出、专家解读随后 | 30~90 秒 |
| **输出项目结论** | 「输出项目「XXX」的评估结论」（或 回顾/查看/读取/导出 + 项目 + 结论/报告） | 判定为对话模式 → 读取本地档案原文 → 复述结论（**不重跑评估**） | 10~30 秒 |
| **自由问答** | 其他任何问题 | Agent 自主调用工具（Steam/B站/搜索/知识库）收集证据后回答，最多 14 次工具调用 | 20~90 秒 |

## 五、回答完成后

- 回答下方出现**建议按钮**（示例）：
  - `📌 输出项目「X」的评估结论`
  - `🔍 深挖该品类头部竞品与差异化机会`
  - `⤓ 导出报告 PDF`
- 这些按钮**随消息保存在本地数据库**：关掉页面、切到别的对话再回来，按钮仍在

## 六、项目档案与多对话

- 侧栏「对话」：`➕ 新建对话`（不同项目建议分开）、点击切换、`✕` 删除
- 侧栏「项目档案」：点击项目 → 跳转到该项目的评估对话；每行 `📌 结论`（输出结论）/ `⤓ PDF`（导出报告）/ `✕`（删除档案）
- 生成回答期间：输入框可继续打字（**会保留**），按发送会提示稍候；切换对话/删除会提示稍候

## 七、常见问题排查表

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 页面打不开 / 连接被拒 | 服务未启动 | 双击 `start.bat`（自动清理端口占用） |
| 打开后是**别的界面** | 端口被其他程序占用 | 换端口：改 `.env` 的 `PORT` 后重启；或关闭占用该端口的程序 |
| 点启动提示端口占用 | 旧进程残留 | 新版 `start.bat` 会自动清理；或手动 `netstat -ano` 找 PID 后结束 |
| **中文变成乱码/方块** | 浏览器缓存旧资源 / 连错端口 | **Ctrl+F5 强制刷新**；并核对端口是否为本工具（`/api/health` 应返回 `{"ok":true,"llm":true}`） |
| 一直"正在调研"不动 | 外部接口限流（Steam/B站） | 等待 30~60 秒或稍后重试；工具标签会显示失败原因 |
| 工具标签大量失败 | B站风控 `-799/-412` / Steam 限流 | 属外部限流，已内置重试；错峰重试即可 |
| 想换 LLM | — | 改 `.env` 的 `LLM_BASE_URL` / `LLM_MODEL`（任意 OpenAI 兼容服务，含本地 Ollama） |
| 想清空数据 | — | 停服后删除 `data/` 目录（会丢失知识库，可重新 `node src/ingest/seed.mjs` 播种） |

## 八、给 Agent 的自动化接口

| 接口 | 用途 |
|---|---|
| `POST /api/chat` `{session,message}` | SSE 流：`phase/status/tool/reasoning/delta/report/scores/done/error` |
| `GET /api/history?session=` | 会话消息（含 `meta.suggestions`） |
| `GET /api/sessions` / `GET /api/projects` / `GET /api/stats` | 会话 / 项目档案 / 统计 |
| `POST /api/delete-session` `{session}` / `POST /api/delete-project` `{slug}` | 删除 |
| `POST /api/digest-now` | 立即市场复盘 |
| `POST /api/feedback` `{kind,refId,rating}` | 👍👎 反馈 |
