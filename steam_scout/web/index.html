⚙️ 配置 LLM API

本工具只需一个 OpenAI 兼容的大模型 API 即可使用（Steam / SteamCharts / B 站 / 搜索都是公开接口，无需任何其他 Key）。配置会写入项目根目录的 .env，只保存在本机。

🔌 可选：第三方 / 付费数据源（补充销量·拥有者·在线估算）

默认不启用：只用 Steam 官方接口 + SteamCharts，无需任何 Key。选定哪个数据源，评估就用那个源的数据补齐官方接口缺失的字段（拥有者/销量近似/在线），报告里会注明数据来源。

如实说明（2026-11 逐项实测）：不接第三方源也完全可用，工具已内置 Steam 官方接口 + SteamCharts + 官方在线人数兜底。SteamSpy 免费但对程序请求一律被 Cloudflare 人机验证拦死（换什么请求头都没用），因此不在下拉里默认提供；Gamalytic 能给出销量/收入估算，但 API 需 Starter $25/月起；VG Insights 已被 Sensor Tower 收购，只剩企业版；Steambase 只有网站和 Discord/Slack 机器人，没有公开 API。

常见配置：
• DeepSeek → https://api.deepseek.com，模型 deepseek-chat 或 deepseek-flash（platform.deepseek.com 注册）
• 其他厂商（OpenAI / 智谱 / 通义 / Kimi / SiliconFlow）→ 填各自的 OpenAI 兼容地址与模型名
• 本地 Ollama → http://127.0.0.1:11434/v1，模型如 qwen2.5:7b（无需 Key，随便填 non-empty）

📖 使用指南

① 三步上手

① 立项评估侧栏「📊 评估我的项目」→ 改掉 XXX 里的项目信息发送 → 自动调研 Steam 数据并出评分报告
② 看结论 / 深挖「📌 输出项目评估结论」读档案（不重跑评估）；「🔍 深挖品类与竞品」继续调研
③ 导出报告「⤓ 导出报告 PDF」→ 浏览器打印窗口选「另存为 PDF」

② 怎么开始

  • 立项评估：直接描述你的游戏想法，句中带「立项 / 评估 / 值不值得做 / 多久能上线 / 还能进场吗」→ 自动采集 Steam 实时数据并出评分报告
  • 市场问题：直接问，如「2026 年哪些品类在上升期？」→ 联网调研 + 本地知识库回答
  • 看历史结论：侧栏「快捷功能 ② → 📌 输出项目评估结论」，改掉 XXXXXX 后发送

③ 等待时你会看到

  • 进度条 + 计时：立项评估共 4 步，顶部横幅显示第几步、百分比与已用秒数
  • 滚动话术：每 6 秒更新一句"当前在做什么"
  • 💭 思考过程：推理模型的思考实时可见（可点击折叠）
  • 🔧 工具标签：每次联网查询一条（Steam / B站 / 搜索 / 知识库），悬停可看结果摘要

④ 回答完成后

  • 回答下方出现建议按钮（输出项目结论 / 深挖竞品 / 导出 PDF），点击即继续；关掉页面再回来按钮仍在
  • 项目档案：点击项目 → 跳转对应评估对话；行内 📌 结论 / ⤓ PDF / ✕ 删除
  • 多对话：不同项目建议分开聊，「对话」区可新建 / 切换 / 删除

⑤ 遇到问题

页面打不开双击 start.bat（会自动清理端口占用）
打开后是别的界面端口被其他程序占用：改 .env 的 PORT 后重启
中文显示乱码Ctrl+F5 强制刷新；并确认访问的是本工具（/api/health 返回 {"ok":true,"llm":true}）
一直"正在调研"Steam / B站限流，等 30~60 秒重试；工具标签会显示失败原因
想换模型改 .env 的 LLM_BASE_URL / LLM_MODEL
想要销量/拥有者数据可选接第三方付费源：「⚙️ 配置 LLM API」→ 展开「🔌 第三方 / 付费数据源」→ 选源 + 填 Key → 保存并测试。不接也能用；接了就用那个源的数据补官方缺的字段，报告会注明来源

生成期间可以继续在输入框打草稿（不会丢），发送会提示等待完成。完整流程文档见项目内 docs/交互流程.md，Agent 规格见 SKILL.md。
