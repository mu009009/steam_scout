=====================================================
  Steam 市场侦察兵 (SteamScout)
  游戏立项调研助手 · 解压即用
=====================================================

它能干什么？
  帮你判断一个 Steam 游戏想法值不值得做、大概多久能上线、
  现在进场还来不来得及；也能回答品类趋势、爆款案例、竞品情况。


-----------------------------------------------------
【用法一】最简单：双击 index.html
-----------------------------------------------------
1. 解压整个文件夹
2. 双击 index.html（用 Edge / Chrome 打开）
3. 点右上角「⚙️ 配置」，填入你自己的 LLM API Key
4. 直接开始提问

  这个版本的好处：什么都不用装，双击就用。
  限制：浏览器拿不到 Steam / B站的实时数据，
        所以市场评分是 AI 的定性估计（会标注）；开发周期和上线窗口是精确规则计算。


-----------------------------------------------------
【用法二】要实时数据：双击 start.bat
-----------------------------------------------------
需要电脑装了 Node.js（免费，nodejs.org 下载 LTS 版，一路下一步）
1. 双击 start.bat
2. 浏览器会自动打开 http://127.0.0.1:8792（没自动开就手动输入）
3. 左侧「⚙️ 配置 LLM API」填 Key

  这个版本能做全部事情：实时抓 Steam 新游/竞品/在线人数、B站评测热度、
  项目档案管理、多对话、每天自动市场复盘。


-----------------------------------------------------
【第一步：怎么拿 LLM API Key】
-----------------------------------------------------
推荐用 DeepSeek（便宜、注册即可用）：
  1. 打开 https://platform.deepseek.com
  2. 注册 → 左侧「API Keys」→ 创建
  3. 复制那串 sk- 开头的 Key

其它服务也支持（任选其一，都是 OpenAI 兼容接口）：
  OpenAI      地址 https://api.openai.com/v1          模型 gpt-4o-mini
  智谱 GLM    地址 https://open.bigmodel.cn/api/paas/v4  模型 glm-4-flash
  通义千问    地址 https://dashscope.aliyuncs.com/compatible-mode/v1  模型 qwen-plus
  Kimi        地址 https://api.moonshot.cn/v1          模型 moonshot-v1-8k
  本地 Ollama 地址 http://127.0.0.1:11434/v1           模型 qwen2.5:7b（Key 随便填）

填完点「保存并测试」，显示 ✅ 就可以用了。


-----------------------------------------------------
【怎么用：四步】
-----------------------------------------------------
① 立项评估：输入类似下面这句，改掉书名号里的内容
     评估立项：《我的游戏名》2D 肉鸽卡牌，2人团队，计划12个月上线——值不值得做？
   → 会自动调研并给出：六维市场潜力评分 + 开发周期三档估算 + 上线窗口评级 + 专家解读

② 看结论 / 深挖：点回答下方的建议按钮，或输入
     输出项目「我的游戏名」的评估结论
     分析「肉鸽卡牌」品类当前的市场趋势、竞争格局与进入机会

③ 排周计划（甘特图）：侧栏「🗓 Demo 周级甘特图」，或直接输入
     帮我排《我的游戏名》的 Demo 周级甘特图：目标是可玩 2 章、3 个 Boss、120 张卡，
     8 个关卡、6 万字剧情；团队 3 人全职；对标 2027 年 6 月新品节
   → 信息不全会先反问你 2-3 个问题（目标状态 / 内容体量 / 时间点），补充后再出表
   → 输出：逐周任务表（程序/策划/美术/宣发 + 决策点）、G1-G4 关键 Gate 与通过标准、
     三条硬性纪律、人力分布；档期装不下时会给你「砍内容 / 加人 / 推迟」三种方案的具体数字
   → 点「🖨 甘特图 PDF（横向）」直接打印成 A4 横向 PDF，发给团队

④ 导出：点回答下方的「⤓ 导出PDF」，或在项目档案里点 ⤓ PDF
   → 浏览器打印窗口里选「另存为 PDF」


-----------------------------------------------------
【常见问题】
-----------------------------------------------------
Q: 打开 index.html 一片空白 / 点了没反应？
A: 换 Edge 或 Chrome 打开；如果是单文件版，先点右上「⚙️ 配置」填 Key。

Q: 提示端口被占用（用法二）？
A: 直接双击 start.bat 再试一次——新版会自动清理占用端口的旧进程。

Q: 中文显示乱码？
A: Ctrl + F5 强制刷新页面；并确认地址是 http://127.0.0.1:8792（不是别的程序）。

Q: 评估时提示"无实时数据"或数据缺口？
A: 说明用的是单文件版（浏览器跨域限制）。想要真实数据请用用法二。

Q: 一直"正在调研"不动？
A: Steam / B站接口偶尔限流，等 30~60 秒重试即可；工具标签会显示失败原因。
   本工具内置了「快速失败 + 90 秒采集预算」：Steam 拉不动时会带着已有数据先出报告，
   并在报告里标注数据缺口，不会一直卡住。

Q: 排甘特图时它反复问同一个问题（比如一直问时间点）？
A: 已修。现在：
   1) 时间点支持 13 种写法：明年6月 / 今年12月 / 6月底 / 下个月 / 2027年底 /
      明年上半年 / Q3 / 12个月后 / 半年内 / 2027年6月新品节 / 2027-06-14 …
      直接说「没有硬性时间点」也算已回答；
   2) 以你最新一句为准（后面改的口径会覆盖前面的）；
   3) 最多追问一轮，且只问还缺的项；第二轮一定出表，
      剩下的按默认假设补齐并在报告开头写明用了哪些假设；
   4) 追问开头会先列出「已确认」的信息，你能看出它到底缺什么。

Q: 说到某个具体游戏（比如《幸存者笔记》）时，它会先问我是哪个品类？
A: 这是故意的。新上线的游戏名很容易被误判成"品类"（比如把游戏名当成幸存者like），
   所以工具会先去 Steam 核对这款游戏；查不到就直接问你品类，避免拿错赛道数据。
   你只需回复一句「品类：肉鸽卡牌，2人团队，计划12个月上线」，它会立刻跑完整评估。

Q: 回答里冒出一堆 <｜｜DSML｜｜invoke name="..."> 之类的乱码，然后就停了？
A: 已经修好了。那是模型把"工具调用"写成了普通文字（而不是标准格式），
   旧版会把这段标记直接显示出来、也不执行、于是看起来像卡住。
   现在会自动做三件事：
   1) 这类标记不再显示在屏幕上；
   2) 自动解析成真正的工具调用并执行，界面上会提示
      「🔧 模型把工具调用写成了正文（非标准格式），已自动识别并执行：evaluate_project」；
   3) 每轮开始显示「正在继续分析（第 N 轮，已调用 X 次工具）…」，
      要是真没产出正文，会明确告诉你"没有生成有效正文，请重发一次"，不会静默停住。

Q: 看到 SteamDB 封禁页，是你们工具导致的吗？
A: 不是。本工具只用 Steam 官方商店接口 + SteamCharts，从不访问 SteamDB。
   那张封禁页一般是手动浏览 SteamDB 或使用其他抓取工具造成的。

Q: 想要销量 / 拥有者 / 收入这类 Steam 不公开的数据怎么办？
A: 先说结论：不接任何第三方数据源，这工具就已经免费在跑了。
   它免费能拿到：价格 / 好评率 / 评价数 / 中文支持 / 发行日期 / 标签（Steam 官方接口）、
   24 小时在线峰值（SteamCharts）、当前在线人数（Steam 官方接口，免 Key，SteamCharts 挂了时兜底）、
   品类新游密度 / 即将上线数量 / 热销榜（Steam 商店搜索页）、行业趋势（搜索 + B 站）。
   销量用「评价数 × 35」估算，看量级够用。

   如果你还想要"更准的销量/收入估算"，才需要付费第三方源：
   - gamalytic  要钱（API 需 25 美元/月起），给销量/收入/拥有者估算，
                是目前唯一公开价格和误差范围的。Key 在 gamalytic.com 注册订阅后拿
   - custom     自定义：任何返回 JSON 的接口都能接（如 Apify 抓取器、公司内部数据服务）

   已确认"不能用"的，别再找了：
   - SteamSpy：免费、不用 Key，但它对程序请求一律回 Cloudflare 人机验证页
              （实测换什么请求头都被拦），拿不到数据。所以下拉里已经不提供了。
   - Steambase：只有网站和 Discord / Slack 机器人，没有公开 API
   - VG Insights：已被 Sensor Tower 收购，只剩企业版，要联系商务询价
   - SteamDB：没有 API，而且明确反爬，本工具从不访问它

   另外：Steam 官方申请 Key 的页面要求账号消费满 5 美元，没有权限不是本工具的问题
   —— 本工具的功能一个都不需要那把 Key（在线人数接口本身免 Key）。

Q: 回答写一半就断了（比如表格最后一行只剩「若 3 人中有 2」）？
A: 这是"模型单次回复长度上限"到了（max_tokens），不是工具把内容吃掉了。
   现在会自动处理：
   1) 默认上限从 4096 提到 32768（config.json 里的 llm.maxTokens 可调；
      若你的服务商上限更小，工具会自动按 32768→16384→8192→4096 降级并记住该值）；
   2) 一旦发现被截断，会自动续写（界面上会提示"正在自动续写剩余内容…"→"续写完成"）；
   3) 万一还不够，结尾会明确写"输出长度已达上限，可以让我继续写"。
   提示：推理型模型（deepseek-flash）的"思考过程"也占这份额度，
   所以答案特别长时，跟我说一句「精简一点」会更容易一次写完。

Q: 我的 Key 会被打包/上传吗？
A: 不会。分享包里没有任何 Key；你自己填的 Key 只存在本机
   （单文件版存在浏览器 localStorage，完整版存在 .env 文件）。
